# Deep Music Information Research (DeepMIR)

This repository contains three course assignments for **Deep Music Information Research (DeepMIR)**, covering topics in singer classification, controllable text-to-music generation, and symbolic music generation.

Detailed methodology, implementation, experiments, and results for each assignment are provided in the corresponding **report PDF** inside each folder.

---

## Assignments Overview
1. **Singer Classification**: Focuses on singer recognition tasks, including data preprocessing, model training, and performance evaluation.
2. **Controllable Text-to-Music Generation**: Explores controllable music generation from text descriptions, including model implementation and experimental analysis.
3. **Symbolic Music Generation**: Investigates symbolic music generation methods and their practical implementation and evaluation.
